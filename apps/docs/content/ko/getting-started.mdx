## AI 에이전트로 설치하기

Cursor, Claude Code 등 AI 코딩 어시스턴트에 아래 내용을 붙여넣으세요:

> routar(`@routar/core`)를 이 프로젝트의 API 클라이언트로 추가해줘. 먼저 최신 routar
> 문서를 가져와. Context7 MCP가 설정되어 있으면 `use context7`로, 아니면
> https://routar.vercel.app/llms-full.txt 를 직접 fetch해서. package.json에서 기존
> HTTP 클라이언트를 확인해서, `axios`가 이미 의존성에 있으면 `@routar/axios`를,
> `ky`가 있으면 `@routar/ky`를, 둘 다 없으면 내장 fetch executor를 사용해. 그다음
> Zod 스키마로 API 모델을 정의하고, `endpoint()` + `defineRouter()`로 엔드포인트를
> 묶고, 선택한 executor + `createApi()`로 타입 클라이언트를 만들어줘.
> `@tanstack/react-query`가 이미 의존성에 있다면 `@routar/react-query` 연동은 바로
> 하지 말고 나한테 먼저 물어봐(query key/provider 설정 전체를 건드리는 작업이라
> 별도 단계로 진행해야 해).

## 빠른 시작

### 1. 스키마 정의

```ts
import { z } from 'zod'

const TodoSchema = z.object({
  id: z.number(),
  title: z.string(),
  completed: z.boolean(),
})
```

### 2. 엔드포인트와 라우터 정의

```ts
import { endpoint, defineRouter } from '@routar/core'

const todoRouter = defineRouter('/todos', {
  getList: endpoint({
    method: 'GET',
    path: '/',
    response: z.array(TodoSchema),
  }),
  getDetail: endpoint({
    method: 'GET',
    path: '/:id',
    request: { path: z.object({ id: z.number() }) },
    response: TodoSchema,
  }),
  create: endpoint({
    method: 'POST',
    path: '/',
    request: { body: z.object({ title: z.string() }) },
    response: TodoSchema,
  }),
})
```

### 3. Executor와 API 클라이언트 생성

```ts
import { createApi, createFetchExecutor } from '@routar/core'

const executor = createFetchExecutor('https://api.example.com')
const todoApi  = createApi(executor, todoRouter)
```

### 4. 요청 실행

```ts
const todos = await todoApi.getList({})
const todo  = await todoApi.getDetail({ path: { id: 1 } })
const next  = await todoApi.create({ body: { title: 'buy milk' } })
```

모든 반환 타입은 완전히 추론됩니다. 타입 어노테이션이 필요 없습니다.

### AbortSignal

```ts
const controller = new AbortController()
const todos = await todoApi.getList({}, controller.signal)
controller.abort()
```

## 플러그인 사용

```ts
import { createFetchExecutor, logger } from '@routar/core'

const executor = createFetchExecutor('https://api.example.com', {
  plugins: [logger()],
  retry: 3,
  timeout: 8_000,
})
```

## Axios 사용

```ts
import axios from 'axios'
import { createAxiosExecutor } from '@routar/axios'

const executor = createAxiosExecutor(
  axios.create({ baseURL: 'https://api.example.com' })
)
```
